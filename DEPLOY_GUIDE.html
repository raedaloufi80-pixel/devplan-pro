🚀 نشر DevPlan Pro على الإنترنت

اتبع هذه الخطوات لتشغيل تطبيقك على أي جهاز وأي مكان

✓ مجاني 100%

1

📦 رفع الكود على GitHub

GitHub هو المكان الذي يُحفظ فيه كودك ويتصل منه Vercel.

  1. سجّل حساباً في github.com إذا ما عندك
  2. اضغط "+" ثم "New repository" — سمّه devplan-pro
  3. اتركه Private وأنشئه
  4. ارفع ملفات مجلد devplan-pro عبر زر "uploading an existing file"
💡 ارفع كل الملفات دفعة واحدة بالسحب والإفلات على صفحة GitHub
2

🗄️ إنشاء قاعدة بيانات في Turso (مجاني)

Turso هي قاعدة بيانات SQLite سحابية مجانية تعمل مع Vercel.

  1. سجّل حساباً في turso.tech
  2. اضغط "Create Database" — سمّه devplan واختر أقرب منطقة
  3. بعد الإنشاء: اضغط على قاعدة البيانات ثم Connect → SDK
  4. انسخ Database URL (يبدأ بـ libsql://...) و Auth Token
المتغيرالقيمة
TURSO_DATABASE_URLlibsql://devplan-yourname.turso.io
TURSO_AUTH_TOKENeyJhbGci... (النص الطويل)
3

⚡ نشر على Vercel (مجاني)

Vercel يستضيف تطبيقك ويعطيك رابطاً يعمل من أي مكان.

  1. سجّل في vercel.com باستخدام حساب GitHub
  2. اضغط Add New → Project
  3. اختر مستودع devplan-pro من GitHub
  4. قبل الضغط على Deploy، اضغط Environment Variables وأضف:
الاسمالقيمة
ANTHROPIC_API_KEYمفتاح Anthropic الخاص بك (sk-ant-...)
TURSO_DATABASE_URLlibsql://... (من الخطوة 2)
TURSO_AUTH_TOKENالنص الطويل (من الخطوة 2)
  1. اضغط Deploy وانتظر دقيقتين
  2. ستحصل على رابط مثل: devplan-pro-xyz.vercel.app
💡 هذا الرابط يعمل من الجوال والكمبيوتر وأي جهاز بدون تثبيت أي شيء
4

📱 استخدامه من الجوال

افتح الرابط الذي أعطاك إياه Vercel في أي متصفح على جوالك، والتطبيق يعمل مباشرةً.

💡 يمكنك إضافته لشاشة الهاتف كـ"تطبيق": في Safari اضغط مشاركة ← "أضف إلى الشاشة الرئيسية"
5

🔄 تحديث التطبيق لاحقاً

عند تعديل أي ملف وإعادة رفعه على GitHub، يقوم Vercel تلقائياً بتحديث الموقع خلال دقيقتين.

⚠️ لا ترفع ملف .env.local على GitHub — يحتوي على مفاتيح سرية. أضفه في Vercel فقط عبر Environment Variables.
